# Ảnh cho bài trình bày

Đặt ảnh vào thư mục này đúng tên dưới đây (.jpg, .jpeg, .png hoặc .webp), rồi chạy lại `node slides/build-deck.js`. Ảnh được tự cắt vừa khung; khung nào chưa có ảnh sẽ hiện ô "ẢNH" chờ chèn.

| Tên file | Nội dung | Dùng ở slide |
|---|---|---|
| `logo.png` | Logo SIXDO, nền trong suốt | Bìa, Cảm ơn |
| `cover.jpg` | Ảnh chiến dịch / sàn diễn (khổ dọc) | Bìa, Kết luận, Cảm ơn |
| `runway.jpg` | SIXDO tại NYFW hoặc Shanghai Fashion Week | Thương hiệu |
| `sp1.jpg` | SP1 Floral Woven Long Jumpsuit | Sản phẩm, Tái định vị |
| `sp2.jpg` | SP2 Voile Floral Flared Maxi Dress | Sản phẩm, Tái định vị |
| `sp3-den.jpg` | SP3 Raw Flared Dress, đen | Sản phẩm, Tái định vị |
| `sp3-hong.jpg` | SP3 Raw Flared Dress, hồng | Sản phẩm, Tái định vị |
| `listing-hien-tai.png` | Ảnh chụp màn hình listing Amazon hiện tại | Listing hiện tại |
| `khach-du-thuyen.jpg` | Bối cảnh du thuyền / resort | Chân dung khách hàng |
| `khach-tiec.jpg` | Bối cảnh tiệc trong nhà | Chân dung khách hàng |
